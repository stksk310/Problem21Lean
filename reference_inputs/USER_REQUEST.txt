# 3. ACTUALITY FIREWALL

このprojectではactual factorizationとsigned equalityを型レベルで分離する。

推奨設計は

```text
ambient semigroup element : ℤ
actual coefficients       : ℕ
signed relation coeffs    : ℤ
```

とする。

例えばconceptually

```lean
ActualFactorization4 x
ActualFactorization3 x
SignedRelation3
```

を別の型または明確に別のpredicateとして持たせる。

actual factorizationは必ず非負係数のwitnessを保持すること。

signed equalityから自動的にmembershipを得られるAPIを作ってはならない。

核心的な代数で `Nat.sub` のtruncationに依存してはならない。

# 8. M1 PROOF TARGET — C2

authoritative source:

```text
Journal paper Section 2
frozen verification edition:
02_CANONICAL_REDUCTION.md
dependency node C2
```

C2を可能ならpublication anchor単位に分割する。

## C2.1 PF condition → every nonnegative gap

canonical conditionから、
全nonnegative gap xに対して

```math
W-x ∈ Γ
```

を示す。

publicationのmaximal element argumentを忠実にformalizeする。

## C2.2 Exact two-layer decomposition

Apéry setについて

```text
A0
A1
```

を定義し、

各 `w ∈ Ap(Γ,m)` についてexactly one of the two layersが成立すること、

A0がlower ideal、
A1がupper filter、
A1上のinvolution

```math
ι(w)=W+m-w
```

がorder-reversing involutionであることをformalizeする。

また

```math
Max A1 = (PF \\ {F}) + m
Min A1 = {W-q | q∈Q}
```

に必要なbridgeをformalizeする。

statementをpublicationより強くも弱くも変えないこと。

## C2.3 KEY — support-zero return

actual `q ∈ Q`,
`c = W-q`,
direction `i`,
および

```math
c-n_i ∈ H
```

から

```math
q+n_i ∈ ⟨n_j,n_k⟩
```

を示す。

特に証明では、

```math
if q+n_i-m ∈ Γ
then
F = (c-n_i) + (q+n_i-m) ∈ Γ
```

というsame-element contradictionを保持すること。

さらに、あるactual H-factorizationにpositive `n_i` coefficientがあれば
その「同じfactorization」から1 copyを除いて `q∈Γ` となる、
というprovenanceをLeanで明示する。

結論は

```math
∅ ≠ D(c) ⊆ S_H(q)
```

であり、

```math
D(c)=S_H(q)
```

を誤って証明・仮定してはならない。

## C2.4 Tail gcd firewall

`Q ≠ ∅` のもとで

```math
m = (q+m) + (W-q) - W
```

を使って

```math
m ∈ ℤH
```

を示し、
tail gcdが1であることを導く。

この表示はsigned group equalityであり、
actual nonnegative factorizationとして扱ってはならない。

## C2.5 Four-row selection / tail minimality

contradiction hypothesis

```math
|Q| ≥ 4
```

から4つのdistinct actual rowsを選ぶ。

KEYやcomplement factsが
「Q全体について成立しているため、選んだ4行でも同時に成立する」
というscopeを保持する。

またfour-generated minimalityからtail generatorsのminimalityを得る。
