# P5 proof route

Actual central returns split into PAIR, left PFREE, or formally reversed PFREE.
PAIR produces a signed weak root, which is normalized by a decreasing measure;
actual endpoint returns then give a coefficientwise nonnegative factorization
of the Frobenius gap. PFREE first proves the previously unknown sign `F0 ≥ 1`
from two actual right returns. Two actual left returns reduce the remaining
case to a double-unit configuration, whose pure-tail comparison gives PIN and
two exact signed roots. A final actual right return either absorbs the
Frobenius gap or contradicts criticality after eliminating `m`.
