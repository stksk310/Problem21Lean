# Candidate self-check, not an independent audit ruling

This is the reduced M3A candidate permitted by request §37. The complete
unconditional nonsymmetric G4 theorem is not claimed. The final composition
is conditional on exactly `MinimumOneStatement` and `BoxPositiveExitStatement`.

The submitted verifier requires all of the following before a successful
candidate receipt can be written:

- exact 103-file frozen baseline, independently matched to the frozen Git tree;
- an empty project build directory before the final local/CI build;
- root, all old mathematical modules and all new M3 modules built successfully;
- kernel axiom reports for every new namespace declaration, including generated
  helpers, limited to propext, Classical.choice, and Quot.sound;
- original frozen lexical debt scanner with native_decide/run_tac additionally
  forbidden; scanner regressions and exact theorem-level boundary regressions;
- unmodified original M1, M2A and M2B suites on their own archived distributions;
- acyclic imports with no later terminal exclusion dependency;
- candidate/exact-commit byte equality for every proof, checker and build script;
- clean Linux CI and downloaded artifact SHA256 plus internal manifest checks.

The namespace enumerator is a read-only `run_cmd` in the verification directory.
It prints existing environment names; it creates no theorem or proof. Every
listed name is separately inspected using `#print axioms`. The generated checker
suppresses only Lean's advisory warning about directly naming compiler-generated
auxiliary declarations, because auditing those declarations is intentional.

Reviews are in `verification/m3/INDEPENDENT_REVIEW.md`,
`HERZOG_EXTRACTION_REVIEW.md`, and `COLORCAP_INDEPENDENT_REVIEW.md`.
Each states authorship and coverage. The first review's pending-integration and
primitive-formula caveats are superseded by explicit completion addenda; its
two unproved Appendix B inputs remain applicable. Final build and axiom evidence
remain authoritative over earlier per-file development logs.

Inspect `verification/m3/LOCAL_VERIFICATION.json` for the final source hashes and
local results. Inspect the separate `HANDOFF_RECEIPT_M3.json` for the exact commit,
run attempt, artifact digest and candidate ZIP digest after CI verification.
