factorization.  A finite nonempty set of actual factorizations of the same
element supplies MAX-I.  Subtracting PFIBER gives the coordinate box and ROOT0;
completed Frobenius representations force ROOT-BOX and strictness.

Color reversal is implemented as an exact relabeling and transports every
field needed to build `ChainCore`.  Actual pseudo-Frobenius returns retain full
factorization witnesses, so FI/FJ caps, root caps, slopes and all later packet
arguments preserve same-element provenance.

Euclidean division yields `h,q0,r,e0`.  The completed F row reduces successful
points to the two intrinsic candidates.  Formal reversal orients the deficient
candidate to `J0 < 0`, where COMPACT is a genuine nonnegative factorization.
Pure-H criticality proves the return-level bounds.  In the strict region the
Ak level gives SUM-NOTCH.  Finally SHIFT-NEW is obtained from `h` copies of the
root plus the exact `R_j` row, is applied inside actual EA/EB sources, and its
strict use inside the actual FK source proves FK-STRONG.
